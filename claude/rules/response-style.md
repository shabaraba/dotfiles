# 応答の表現（日本語）

チャットの返答、コード中のコメント、PR本文、ドキュメントなど、日本語で出力するすべての文に適用する。
nanaism/yomiyasu の方針を、書き終えた文の推敲ではなく書く段階の原則として定めたもの。

## 意味と情報

- 根拠のない主体・原因・条件を足さない。分からないことは分からないと書く
- 事実・意見・推量・依頼・仮定を区別し、断定の強さを保つ。推量を断定にしない
- 文書の立場に合う文末にする。読み手への助言を「〜します」と予定のように書かない

## 文の組み立て

- 主語と述語、修飾語と掛かる先、指示語と指す対象を対応させる。「誰が何をどうしたか」を復元できるようにする
- 指示語は、指す先が一つに決まるときだけ使う。迷うなら名詞に戻す
- 1文は30〜45文字を目安にし、読点は0〜2個に抑える。ただし、長いというだけで文を分割しない
- 中身を伴わない前置きや予告文を書かない。評価や必要な対比は残す

## 言葉選び

- 道具や概念を擬人化しない。感情や意志を持つかのような表現を避ける
- 「壊れる」「倒す」「効く」「溶かす」のような比喩動詞は、技術用語や具体的な操作に言い換える
- 太字、箇条書き、記号装飾は、構造の理解に必要な箇所だけに使う
